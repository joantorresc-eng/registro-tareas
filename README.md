# Registro de tareas diarias

Sistema simple para organizar las tareas del día: registras una tarea, la terminas con una descripción y el sistema calcula cuánto duró.

# Características

- Registro de tareas con fecha y hora de inicio
- Cierre de tarea con descripción de lo realizado
- Cálculo automático de la duración
- Datos guardados en el navegador (localStorage), sin base de datos

## Uso

1. Escribe una tarea y pulsa **Iniciar tarea**.
2. Al finalizar, describe lo que hiciste y pulsa **Terminar tarea**.

## Tecnologías

HTML, CSS y JavaScript.
